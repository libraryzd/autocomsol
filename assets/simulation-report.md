## Task and main findings / 仿真任务与主要结果

Explain the task, scope and the answer supported by the available results. State the adopted model/run and whether further validation was selected, passed, failed, blocked or skipped. Avoid a claim of validation from solver success alone.

## Adopted method / 实际采用的方法

Summarize the scientific basis and final COMSOL method, referring to the final plan for complete settings. Identify model/source versions and key assumptions. Both documents must agree on all active settings.

## Results and physical interpretation / 结果与物理解释

Present the requested quantities with units, operating points, datasets/solution indices and sources. Include useful figures/tables and explain trends against the task objective and theory. Separate computed observations from interpretation and limitations.

## Selected validation and limitations / 已选验证与局限

Record the user's choices and each study's actual status. For selected mesh/tolerance studies, show triplets, declared metrics, differences, iteration history and final settings. For reference cases, cite exact sources and quantitative comparisons. Explicitly label skipped/blocked/failed items. Do not perform unselected checks just to populate this section.

## Changes and resolved problems / 方案变更与已解决问题

Summarize consequential changes from the original plan, why they were made, evidence supporting the fix and any relevant scope approval. Link the concise error lessons and full logs without dumping stack traces into the main report.

## Deliverables and reproduction / 交付与复现

List final model, simulation/postprocessing sources, inputs, result files, figures and final plan. Explain environment, entrypoints, dependencies and execution limits. Describe only reproduction checks actually performed; generating reproduction instructions does not authorize another solve.

## Sources / 参考资料

Include verified sources for material data, theoretical assumptions, COMSOL APIs and reference cases, with version/page/figure details where available. Preserve original citation titles; write the surrounding explanation in the selected document language.
